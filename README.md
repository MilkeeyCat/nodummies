# Nodummies

A linux kernel module which will punish you for playing with a dummy(you better
don't try to connect a dummy!).

<video src="https://github.com/user-attachments/assets/3fa8b249-9d3b-4060-94de-498232f09a01"></video>

# Required packages

The only package required is linux headers which can be installed by running
`sudo apt install linux-headers-$(uname -r)`. I personally developed and tested
on kernel version 6.1.0(debian btw), that's the only kernel version that is 100%
guaranteed to work.
